## sharp-edges (API surface introduced here) — for L6

| # | Sev | Edge | Why it bites | Required in L6 |
|---|---|---|---|---|
| SE-1 | **High** | Studio `upload` takes a **file path from the renderer** (`UploadInput.file: string`, via `resolveFile`). | A compromised or buggy renderer could name any file the user can read (`~/.ssh/id_ed25519`, the wallet DB); the main process would transcode and **publish** it. Renderer-supplied paths are attacker input under the Electron threat model. | Main process accepts only files the user chose **in main** (dialog) or dropped (preload `webUtils.getPathForFile` → main mints an **opaque, single-use token**); `studio.upload` takes the token, never a raw path. Test: a raw path over IPC is refused. |
| SE-2 | High | Watch `onMiniPlayer(session, …)` is a **fire-and-forget transfer of a billing session**; Watch detaches first. Also fires on unmount, so a shell that remounts Watch video→video is handed the old session. | A shell that ignores or drops the callback leaks a live `PlaySession` with no owner — it keeps its replication stream and pays for its prefetch window with nothing on screen. | One app-wide **playback coordinator** in the shell owns every `PlaySession`: at most one live paying session; adopting a hand-off is the only path; dismiss/replace always `close()`s. Test: navigate Watch→Watch and Watch→Home; assert exactly one open session and none leaked. |
| SE-3 | Medium | Shorts `onPlaybackStart(videoId)` is **optional**; omitted, the mini-player and a short **bill concurrently**. | Pit of failure: the default (no prop) double-bills. | Same coordinator: starting any session pauses/closes the other. Wire `onPlaybackStart` to it. |
| SE-4 | Medium | Auto top-up "off" is the **sentinel `belowSats: 0`** (v4 cannot clear the optional key). | Safe only if the trigger is `balance < belowSats`. An implementation using `<=` would top up whenever a mint hits 0 — moving money the user switched off. | Treat `belowSats <= 0` as **disabled explicitly**, with a test; v5 makes it nullable. |
| SE-5 | Low | `unreact(videoId)` (v4). | Must never be implemented as a `-` reaction (dislikes are public) and must only target the viewer's own kind-7 ids. | NIP-09 kind-5 deletion referencing the viewer's own reaction ids; test that no `-` is published. |

`myReaction` absent = neutral (a stale value only means a replaced reaction — newest wins; no
money or privacy impact). Watch's `resumeSession` is guarded (video id must match; a spent
session is never re-adopted).
