### `packages/app-desktop/src/worker/transcode/` — Bare adapter

`createBareProcessRunner(spawn, {env?}): ProcessRunner` with an **injected** `spawn` (production: `require('bare-subprocess').spawn`; tests: a fake — the addon cannot load under Node, S-C f.8). **Catches the synchronous `spawn()` throw on ENOENT/EACCES (S-C finding 9)** and rejects with `ProcessRunnerError { code:'spawn-failed', errno:'ENOENT', file }`; also maps async `'error'`, signal exits (→ `-1`), and abort (→ `kill('SIGKILL')`, `code:'aborted'`). `bare-subprocess-types.ts` declares only the surface used. `ProcessRunnerError` is duplicated here (same shape; recognised structurally by core) because `media/` is not yet exported from `@sovit/core` — swap for an import at wiring time.

## Assumptions

- **Ladder is keyed on display height** (after rotation). A portrait 1080×1920 phone clip gets 1080p/720p/360p at 608/406/202 px wide. The contract labels say "never taller than the source" — honoured.
- **Placeholder** = 32 px-wide JPEG q12 (~500 bytes → ~700 chars base64), attached to every rendition's `placeholder` in the draft. Thumbnails and storyboard are emitted as `{path, sha256}` so T16's `x` can be carried once they are Blossom-uploaded (out of this lane).
- **Storyboard VTT** points at `storyboard.jpg` relative; L1/T16 rewrites to the Blossom URL. Tile size is derived from the probed sprite dims (`ffprobe` on the JPEG), not assumed.
- **`webm` renditions** (only when `codec:'vp9'` is requested): the contract's `faststart: true` literal is set without an MP4 check because WebM has no `moov`. Only tested through the fake runner, not the real binary (H.264/MP4 is the default and the tested path).
- Work directory: `opts.workDir` or `fs.mkdtemp('nutflix-transcode-')`; outputs are `<workDir>/<label>.<ext>`, `thumb-N.jpg`, `placeholder.jpg`, `storyboard.{jpg,vtt}`. Paths are joined with `/`. The pipeline never deletes; `runStudioUpload` removes the work dir only when `removeWorkDir: true`.
- `MediaProbe.faststart` is populated only for MP4/MOV containers (decided from the first chunk(s) via the streaming scanner; a malformed box structure reads as `false`).
- `TranscodeProgress` `probe` and `write` stages are defined in the contract but not emitted by `transcode` (probe happens in `probe()`, writes in `publish()`); `runStudioUpload` synthesises `writing` percent by wrapping the sink.
- The `bare-subprocess` adapter takes `spawn` by injection rather than importing the package, so it is type-checked/tested under Node and L6's worker does the one `require`.
- Cameron's open question (shipped GPL ffmpeg in the desktop bundle): the binary path is injected config everywhere (`MediaPipelineDeps.binaries`), and the GPL build is only the dev/test pin — the design is indifferent to the answer.

## Uncertainties / things to reconcile

1. **`hyperUrl` blob-id encoding.** The contract comment says `hyper://<z32 core key>/<blob-id-encoded>`, the build-plan says `<core-key-hex>/<blob-id>`, and the fixtures use `hyper://<hex>/<blockOffset>-<blockLength>`. I followed the fixtures (the only concrete convention in the repo) as `defaultHyperUrl` and made it injectable (`deps.hyperUrl`). L1 owns the real format; the orchestrator should inject theirs.
2. **Error shape.** `contracts/media.ts` defines none, so I defined `MediaError`/`ProcessRunnerError` in `media/errors.ts` and duplicated the runner error class in app-desktop (structurally identical). If a shared error contract is wanted later, that is a v3 item — not requested now.
3. `RenditionDraft`/`UploadDraft` are my shapes for the L1 handoff (rendition minus Blossom-dependent `image`/`captions`/`storyboard`, plus `thumbnail` and `storyboard` with paths+sha256). L1 may prefer different names.
4. `-ss` before `-i` (fast seek) is used for thumbnails; for sources with unusual start offsets a frame may land slightly off the requested second. Acceptable for candidates.
5. bare-subprocess DOES ship an `index.d.ts` (the brief said it does not); I still wrote a minimal local surface type because its d.ts pulls in `bare-events`/`bare-pipe`/`bare-stream`, and injection keeps the adapter free of any `bare-*` import.
