## Protocol surface (renderer ⇄ main ⇄ host)

`IPC_V = 1`. `CHANNEL = { call: 'nf:call', sub: 'nf:sub', event: 'nf:event', grant: 'nf:grant-file' }`.
Every message carries `v`. Handlers never throw across `ipcMain.handle`: they resolve a
`ReplyMsg` (`{v, id, ok: true, result}` | `{v, id, ok: false, error: WireError}`).

**Compile-time exactness** (bottom of `protocol.ts`, no JS emitted): the build fails, naming the
member, when contracts v5 adds/removes an adapter or wallet method (`UncoveredMethods<A>` must be
`never`), when a table entry's arguments differ from the contract's parameters, when a rehydrated
result differs from the contract's result (both directions), when a topic payload differs from
the callback argument it replaces, when `PlaySession` gains a field or method the wire lacks, or
when core's `MediaErrorCode` and the runtime `MEDIA_ERROR_CODES` list drift. The only deliberate
non-identities are `studio.upload`'s argument (SE-1), `play`'s result (data only) and `image`'s
result (narrowed). `protocol.test.ts` shows a fake v5 adapter surfacing as uncovered.

## Host ⇄ worker protocol

Framed JSON over the pear-runtime/bare-sidecar pipe. Requests `{op:'req', id, m, a}` where `a` is
one object; responses `{op:'res', id, ok:true, r?}` | `{op:'res', id, ok:false, e: WireError}`;
events `{op:'ev', e, …fields}` (worker → host only). Each direction numbers its own ids.

| Direction | Name | Args → result |
|---|---|---|
| host → worker | `init` | `{v, storage, seeding, prefetchSeconds, ffmpeg?, dev?}` → — |
| | `play.open` | `{sid, videoId, rendition:{label, hyper, size, bitrateKbps?}, durationSec?, policy, prefetchSeconds}` → `{key, link: http://127.0.0.1:<port>/…}` |
| | `play.pause` / `.resume` / `.close` | `{sid}` → — |
| | `play.prefetch` | `{sid, seconds}` → — |
| | `seeder.status` | `{}` → `SeederStatusWire` |
| | `seeder.configure` | `{enabled, diskCapBytes}` → — |
| | `seeder.melt` / `.unban` | `{mint, bolt11}` → `{paid}` / `{pubkey}` → — |
| | `studio.ffmpeg` | `{recheck, path?}` → `FfmpegStatus` |
| | `studio.upload` | `{uploadId, path, name, meta, thumbnailChoice?: number \| {hex, type}}` → `VideoManifest` |
| worker → host | `studio.publish` | `PublishDraft` → `VideoManifest` (host adds `creatorP2pk`, `publishedAt`, `blossomServers`, signs) |
| events | `ready {v, port}`, `spend {sid, mint, amount, total, ratePerMin}`, `peers {sid, peers}`, `seeder.status {status}`, `upload.progress {uploadId, progress}`, `dev.fixtures {videos}`, `log {level, msg}` | |

Guards: `validateWorkerArgs`, `validateWorkerResult`, `validateHostArgs`, `validateHostResult`,
`validateWorkerEvent` (each a complete mapped table — a missing entry is a compile error) and the
frame-level `isHostToWorker` (worker side) / `isWorkerToHost` (host side). The `--dev-mocks`
fence (D1) is in the guard: `init.dev.bootstrap` is accepted only with `dev.mocks: true` and only
`{host: '127.0.0.1'}` entries.

## Bare globals (finding; coordinator correction 2026-09-23)

Run under `node_modules/bare-sidecar/prebuilds/linux-x64/bare` (Bare **1.31.0**, V8 14.8) and
asserted by `sidecar.test.ts` on every CI run: `TextEncoder`, `TextDecoder`, `crypto`,
`AbortController`, `process`, `fetch`, `WebSocket`, `performance`, `EventTarget` are
**undefined**; `URL`, `Buffer`, `queueMicrotask`, timers, `structuredClone`, `console`,
`atob`/`btoa` exist (Bare's `/src/bare.js` "Step 7" installs exactly these). Consequences:

- `src/ipc` uses no global beyond `Uint8Array`/`DataView`/`JSON`/`Map`/`RegExp`; UTF-8 is a
  strict pure-TS codec (`codec.ts`), injectable through `FramingOptions.codec`.
- **Not `b4a`** (the coordinator suggested it): `b4a` is not a dependency of
  `@sovit/app-desktop` (only transitive), ships no types, and its `toString(buf, 'utf8')` replaces
  invalid bytes with U+FFFD — a corrupted frame would decode into a different message instead of
  failing. The codec matches `TextEncoder` byte for byte and a FATAL `TextDecoder` exactly
  (fast-check against Node's as the oracle). If the worker wants native speed it can inject a
  `b4a`-backed codec that throws on U+FFFD.
- `src/ipc` never imports `@sovit/core` at runtime (type imports are erased): its root barrel
  loads nostr-tools, which calls `new TextDecoder()` at module load. `MediaError` and
  `ProcessRunnerError` are recognised structurally.
- **Not only `src/ipc`:** `@sovit/core/media`'s `pipeline.ts:36` (`const decoder = new
  TextDecoder()` at module load) and `@sovit/seeder`'s `store/json-store.ts:23` use
  `TextDecoder`, and L8's `bare-process-runner.ts:108` does `new TextDecoder()` inside `run`.
  L6-C must either install a small `TextEncoder`/`TextDecoder` polyfill in the worker entry before
  loading those modules, or get them changed — the day-1 Bare probe will hit this.

## tsconfig layout (and why `src/ipc` lives in the worker project)

Every part is a composite project with `rootDir: "src"` and `outDir: "dist"`, and includes only
`src/<part>/**` — so each emits under `dist/<part>/`, and a relative import such as
`../ipc/protocol.js` resolves identically in `src/` and `dist/` (Electron main loads
`dist/main/main.js`, which imports `dist/ipc/…`). Part-specific `outDir: "dist/<part>"` with
`rootDir: "src/<part>"` would break every cross-part import (`TS6059`), and `rootDir: "src"` with
`outDir: "dist/<part>"` would emit `dist/main/main/main.js`.

The shared code (`src/ipc/**`, `src/index.ts`) must belong to exactly one project that the others
reference. A sixth `tsconfig.shared.json` was outside the lane allowlist, so it lives in
`tsconfig.worker.json` — the strictest environment (no DOM lib), which is the right default for
code that must run under Bare anyway. main/host/preload/renderer reference the worker project.
The package entry is unchanged: **`dist/index.js` + `dist/index.d.ts`, `dist/worker/transcode/*`
exactly as before — no `package.json` change is needed.** Configs whose directories do not exist
yet (main, preload, renderer, and host apart from its test) compile to nothing without error, so
no placeholder directories were added. A probe (since deleted) with a file in each of
`src/{main,preload,renderer}` importing the ipc barrel compiled and emitted to `dist/<part>/`.

`types` per part: worker/host/main keep `["node"]` from the base; preload and renderer set
`types: []` so `process`/`require`/`Buffer` do not type-check there. The worker keeps Node types
because L8's code and the Node-run tests need them; `boundaries.test.ts` and the sidecar test
enforce Bare-safety instead of the compiler. `bare.d.ts` is included by the worker project only;
`pear-runtime.d.ts` by the host project only.

`vitest.config.ts`: include `src/**/__tests__/**/*.test.ts(x)`, exclude `e2e/**`, default
environment `node` (it was `jsdom`; the transcode tests pass under node). Renderer tests opt in
with a `// @vitest-environment jsdom` docblock.

## Deviations from design §2 (and why)

1. **`void` results are `undefined`** (`MethodTable[m][1]`): that is what a structured-clone or
   JSON reply carries; the exactness check maps the contract's `Promise<void>` onto it.
2. **More `LIMITS`** (design had 5): `maxPlaylistItems` 1000, `maxUrl` 2048, `maxServerUrl` 512
   (= Settings' `MAX_URL_LENGTH`), `maxTag`, `maxLabel`, `maxPage` 200, `maxPrefetchSec` 600,
   `maxSats`, `maxDiskCapBytes` (= Settings' 10 000 GB), `maxAutoTopUpSats` (= Settings'),
   `maxThumbnailBytes` 5 MiB, `maxErrorMessage` 512, `maxPath`, `maxDepth` 64. The design's five
   keep their values.
3. **`wallet.balance`** is bridged (read-only) in addition to the design's list;
   **`wallet.p2pkPubkey` and `wallet.keyset` are excluded** with `wallet.send`/`receive` —
   nothing in v4's UI calls them and both are engine plumbing. Ask if a screen needs either.
4. **`UploadId` is branded** and `thumbnailChoice` bytes carry `ImageMime` (jpeg/png/webp), not
   any string. `FileToken` has a fixed shape (`nf-file:` + 32 hex) so the guard is exact.
5. **`image` returns `NfMediaImgUrl`** (CSP `img-src 'self' nf-media: data:`); `image` also
   ACCEPTS `nf-media://img/<id>` because Studio passes thumbnail candidates back through it.
6. **`HostOut` gains `sub-reply`** (the ack for `nf:sub`, whose `ReplyMsg.id` is the `subId`) and
   `image.type` is `ImageMime | null`. `HostIn.msg` is `AnyCallMsg` (discriminated on `method`).
7. **`EXCLUDED_METHODS` / `TOPIC_METHODS` / `ShellMethod`** make the "exhaustive except D3"
   rule mechanical; `validateArgs` lives in `guards.ts` (design had a `declare const` in
   `protocol.ts`).
8. **Worker protocol shapes were not specified in §2**; decided here: object args (`a`), `init`
   returns nothing and `ready{v, port}` follows it, `seeder.configure` carries the pushed
   settings (instead of an open-ended `seeder.*`), `spend` carries the per-PAY `amount` + `mint`
   so the host can debit `MockWallet` (§1 "Wallet and engine"), `play.open` takes the rendition's
   `HyperblobRef` + `policy` + prefetch/bitrate inputs, `studio.publish` takes a JSON-safe
   `PublishDraft` (not core's `UploadDraft`, which holds `TranscodeOutput` and raw bytes), and
   bytes on this hop are lower-case hex (`ThumbnailHex`).
9. **Framing extras:** a frame must be a JSON object; a zero-length frame is an error; the
   encoder refuses Map/Set/typed arrays/functions (JSON would silently turn them into `{}`).
10. **UTF-8 without b4a** — see "Bare globals".

## What lanes A/B/C must know

- **Everyone:** import from `../ipc/index.js` (or the specific module). Guards return booleans and
  never throw; reject with `wireError('invalid-argument', …)`. Always cross errors with
  `toWireError` (sender) and `fromWireError` (receiver); never forward `err.message` yourself.
  Never put a `Map` on a wire — `dehydrate` before sending, `rehydrate` after receiving.
- **L6-A (main/preload/renderer):** main checks the sender frame, then `isCallMsg` / `isSubMsg` /
  `isGrantFileMsg`, enforces `LIMITS.inflightPerWc` / `subsPerWc` (`rate-limited`), swaps
  `UploadInputWire.file` for the path only on `studio.upload` (anything else →
  `file-token-invalid`) and sends it as `HostIn.file`; `isHostOut` before acting on host output
  (media links must be `http://127.0.0.1:<port>/`). **SE-1 sharp edge:** `isGrantFileMsg` only
  checks that `path` is absolute — the protection is that the renderer can never supply it. The
  preload's grant function must take a DOM `File` (never a string) and pass
  `webUtils.getPathForFile(file)`; that is `''` for a renderer-constructed `new File(...)`, so main
  must refuse an empty path, `lstat` it (regular file) and mint single-use tokens bound to the
  webContents. The preload subscribes to `upload.progress`
  BEFORE calling `studio.upload`, builds `PlaySession` around `sid`, and exposes stubs for
  `EXCLUDED_METHODS` that reject `fromWireError(wireError('forbidden', …))`. `rehydrate` in the
  renderer turns `$map` back into Maps; `IpcError` carries `.code`.
- **L6-B (host):** run `isHostIn` on every parentPort message (it re-validates args) and
  `isWorkerToHost` + `validateWorkerResult[m]` on everything from the worker. Void replies must
  still carry `result: undefined` on the Electron hops (`isReplyMsg` requires the key). Drain the
  sidecar's stdout/stderr. `import PearRuntime from 'pear-runtime'` loads corestore, hyperswarm
  and three native addons into the Node host at import time (measured 239 modules incl.
  sodium-native, rocksdb-native, rabin-native) although `run` needs none of it — see open
  question 1. Only `PearRuntime.run(entry, args)` type-checks; `new PearRuntime()` does not (D2).
  SE-4: `updateSettings` accepts `autoTopUp.belowSats: 0` (the v4 "off" sentinel); treating
  `<= 0` as disabled is your code's job. `validateArgs.image` accepts any `https:` host,
  loopback and private literals included (a guard cannot resolve DNS): refusing those, the 5 MiB
  cap, redirects and the sha256 check are `host/images.ts`'s job (design §3).
- **L6-C (worker):** `Bare.IPC` delivers unframed chunks; feed them to one `FrameDecoder`, run
  `isHostToWorker` + `validateHostResult[m]`, and on a `FramingError` exit (no resync — the
  fixture uses exit code 3). Attaching a `'close'` listener to `Bare.IPC` disables bare-sidecar's
  auto-exit on pipe close (`lib/runtime.js:8-30`). An unhandled `uncaughtException`/
  `unhandledRejection` ABORTS Bare unless `Bare.on(...)` handles it. Bare has no
  `TextEncoder`/`TextDecoder`/`crypto`/`AbortController`/`process`, and three already-merged
  modules you will load need `TextDecoder` (see "Bare globals"). Enforce the dev-mocks fence in
  code too (the guard already refuses a non-loopback bootstrap).

## Open questions / decisions for the orchestrator

1. **Host spawning without pear-runtime's import cost.** `PearRuntime.run` is literally
   `new (require('bare-sidecar'))(entry, args)` under Node. Importing `bare-sidecar` directly
   keeps native addons out of the host (ADR 0003's intent) but needs `bare-sidecar` (0.5.4,
   currently transitive) added to `@sovit/app-desktop`'s dependencies. Design D2 is satisfied
   either way.
2. **`TextDecoder` in core media / seeder / L8 under Bare** (see "Bare globals"): polyfill in the
   worker entry (L6-C) or change those modules (orchestrator-owned).
3. Should `wallet.p2pkPubkey` / `wallet.keyset` be bridged (deviation 3)?
4. `docs/contract-requests`: none now. For v5, consider re-documenting `UploadInput.file` —
   "Desktop: absolute path" is no longer what crosses into the shell (SE-1: a token).
